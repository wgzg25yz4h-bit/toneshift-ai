# ToneShift UI/UX refinement

## Build
- Refine the page into the selected editorial broadsheet direction while keeping the existing warm palette, content, and workflow.
- Strengthen the path from the concise introduction into a premium, clearly labeled writing surface.
- Redesign tone choices with compact descriptions, icons, visible selected checks, focus states, and subtle hover elevation.
- Make the translation action unmistakable and replace the spinner with a restrained animated ellipsis/spark treatment.
- Give the generated message a distinct output stage with status, copy feedback, and retry controls.
- Harmonize navigation, supporting sections, spacing, typography, borders, and motion across the page.

## Responsive and accessibility
- Keep tone options 2×2 where practical, stacking only on narrow screens.
- Maintain 44px tap targets, readable text, visible keyboard focus, labels, status announcements, and no horizontal overflow.
- Respect reduced-motion preferences and verify desktop and mobile flows in the live preview.
